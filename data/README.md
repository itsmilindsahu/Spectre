# Data Directory

- `raw/` — unmodified spectra as downloaded from source databases (NIST
  WebBook, SDBS, Coblentz, etc.). **Empty in this repo** — see below.
- `labeled/` — spectra paired with auto-generated functional-group labels
  (via RDKit SMARTS matching against known SMILES structures). Also empty
  here — this is generated by a script, not committed as static data.

## Why this directory ships empty

Redistribution terms differ by source (NIST WebBook and SDBS both have
usage restrictions that don't clearly permit bulk redistribution of raw
spectral data). Rather than risk a licensing violation, this repo ships
**fetch scripts, not the data itself** — each contributor pulls their own
copy locally.

## Getting started with real data

1. `examples/sample_spectrum.csv` and `examples/sample_spectrum_alcohol.csv`
   are **synthetic** spectra (Gaussian-peak-generated, not real instrument
   data) included so the pipeline is runnable and testable without any
   external downloads. Use these to verify your local setup works.
2. For real data, a fetch script for NIST WebBook / SDBS should be added
   here (`data/fetch_nist.py`, `data/fetch_sdbs.py`) — not yet implemented,
   good first contribution.
3. Labeled training data (for Phase 2/3 ML models) should be generated via
   `spectre/models/labeling.py` (not yet implemented) using RDKit SMARTS
   patterns against each compound's known SMILES string — this is where
   the chemistry track's domain expertise becomes structured training data.

## Format convention

All spectra in this project are standardized to CSV with two columns:
`wavenumber_cm-1, absorbance`, in descending wavenumber order (4000 → 400),
OR the original JCAMP-DX file if working with the raw parser directly.
