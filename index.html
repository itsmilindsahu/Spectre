Admin setup — connect central logging (Google Sheet)

This page runs entirely client-side (safe for GitHub Pages — no backend). Every run is saved to the visiting browser's local storage, and a Download local log (.csv) button lets any user export what happened in their own browser. To collect submissions from everyone in one place, wire up a free Google Sheet + Apps Script endpoint:

  1. Create a new Google Sheet, e.g. Spectre Submissions.
  2. Open Extensions → Apps Script, delete the placeholder code, and paste in the contents of sheet-logger.gs (shipped alongside this file).
  3. Click Deploy → New deployment, type = Web app, execute as Me, access = Anyone.
  4. Copy the deployment URL and paste it into the SHEET_ENDPOINT constant near the top of the <script> block in this file.
  5. Re-upload this file to your GitHub Pages repo. Every future submission will silently POST to that sheet in addition to being logged locally.

Until SHEET_ENDPOINT is set, the tool works fully — logging just stays local to each visitor's browser.

Admin setup — deploy the CNN (Phase 3)

The CNN classifier runs entirely in the visitor's browser via onnxruntime-web (loaded from a CDN, no install needed) — no Python backend, same as everything else on this page.

  1. Train a checkpoint: python scripts/train_cnn.py (from the main Spectre repo, not this web folder).
  2. Export it: python scripts/export_onnx.py — this writes web/cnn_ir.onnx and web/cnn_ir_labels.json.
  3. Push both files to your GitHub Pages repo in the same folder as this index.html — the page fetches them by relative path (cnn_ir.onnx, cnn_ir_labels.json).
  4. That's it — the "CNN (Phase 3)" option in the classifier dropdown will load and run them on first use.

This deployment already ships a checkpoint trained on synthetic data (see spectre/synthetic/generator.py in the main repo) — retrain on real labeled spectra once available and re-export to replace it.
